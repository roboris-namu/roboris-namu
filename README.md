### 👋 소개

약 7년간 다양한 산업군(반도체·금융·교육·제조)의 IT 시스템을 **개발·운영**해 온 실무형 개발자입니다.
특히 **CJ제일제당 EHS 시스템을 2년 9개월간 단독 운영 담당자**로 책임지며, 불안정했던 시스템을
안정화하고 사용자 수를 **800명 → 3,000명 이상**으로 확장했습니다.

요즘은 운영에서 한 걸음 더 나아가, **RAG 기반 AI 앱**과 **인디 앱 브랜드 SLOX**를 직접 만들며
"기획 → 개발 → 출시 → 운영"의 전 과정을 1인으로 굴리고 있습니다.

### 🚗 대표 프로젝트 — 정비도사 (RAG AI)

> **RAG 기반 한국어 자동차 정비 챗봇** · 아주대 대학원 AI 실무과정 팀 프로젝트 **(팀장)**

일반 LLM의 "그럴듯한 거짓말"(환각)을 막기 위해, **엄선된 정비 지식만 근거로 답하는** RAG 파이프라인을 설계·구현했습니다.

| 항목 | 내용 |
|------|------|
| 역할 | 기획 · 아키텍처 · 백엔드 (팀장) |

| 특징 | 답변마다 `[S1][S2]` 출처 마커 필수 · 환각률 < 2% · 평균 응답 1.5s |
